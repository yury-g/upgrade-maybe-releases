Upgrade, Maybe 2.2.0 Build 16 keeps the Evidence Dashboard readable across split-screen, short-window, tablet, and phone-sized layouts while preserving the same local evidence and assessment rules.

### Responsive Evidence Dashboard

- The sticky evidence rail and the main dashboard now stay in separate columns at desktop sizes.
- Intermediate and short-height windows collapse earlier, wrap long labels safely, and keep every bottom detail tile readable and clickable.
- Phone and tablet layouts no longer create unintended horizontal page overflow.
- The exact customer-reported desktop geometry and a permanent responsive-width matrix are covered by regression tests.

### Branded local dashboard

- The app opens `upgrademaybe.localhost:8765` after a successful local health check.
- `127.0.0.1:8765` remains an intentional visible fallback if that branded-host check is unavailable.
- Both names resolve to the same service bound only to numeric loopback. Exact Host and Origin checks remain enforced, and neither address is the public website.

### Install

1. Download and open the DMG.
2. Double-click **Upgrade, Maybe.pkg** with the Rally Flags icon.
3. Follow the standard macOS Installer steps.
4. Use your Mac normally. Upgrade, Maybe continues observing locally from the menu bar.

### Requirements

- Apple-silicon Mac
- macOS 13.5 or newer
