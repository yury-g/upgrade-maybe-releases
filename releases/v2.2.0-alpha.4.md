Upgrade, Maybe 2.2.0 Build 13 puts useful visual evidence first while preserving the existing assessment contract and local history.

### Visual-first native layout

- The concise verdict, Comfort/Strain, system-resource chart, and running-app cards now appear before long-form assessment detail.
- Evidence stage, next action, rationale, and what-could-change detail remain available as the final section in the same semantic and accessibility order.
- Guided and Pro presentations continue to use the same local AssessmentV1 authority as the Evidence Dashboard.

### Reliability

- History processing now streams stored observations instead of materializing the complete result set, reducing collector CPU and memory pressure without changing evidence meaning.
- The five-valid-minute, five-valid-hour, and two-adequately-observed-days contract is unchanged.
- Synthetic samples remain excluded, missing evidence stays explicit, and short windows cannot produce an upgrade conclusion.

### Install

1. Download and open the DMG.
2. Double-click **Install Upgrade, Maybe.pkg** with the Rally Flags icon.
3. Follow the standard macOS Installer steps.
4. Use your Mac normally. Upgrade, Maybe continues observing locally from the menu bar.

### Requirements

- Apple-silicon Mac
- macOS 13.5 or newer
