# Upgrade, Maybe 2.2.0 Build 19

Build 19 is the one-time bridge to automatic, signed in-app updates for the directly distributed Mac app.

## Automatic updates

- Upgrade, Maybe checks the production HTTPS update feed about once per day.
- Signed updates download quietly in the background and install when ready, then the app relaunches on the newer numeric build.
- Automatic checks and installation are enabled by default. You can change automatic installation or manually check from the app.
- Every update must pass Sparkle Ed25519 verification, Developer ID code-signature checks, Apple notarization, stapling, and Gatekeeper validation before publication.

## Your local history stays local

- The app and its bundled collector move forward together from one sealed update payload.
- Monitoring history, benchmark results, logs, and other user data are preserved during component refresh.
- Build 18 → 19 was exercised through a private loopback-only sandbox, including rejection of a tampered archive and verification that production history and agents were untouched.
- These updates cover Upgrade, Maybe and its collector. They do not update Mac firmware or macOS.

## Install Build 19 once

1. Download and open `Upgrade-Maybe-2.2.0-build-19-Public-Alpha.dmg`.
2. Double-click **Upgrade, Maybe.pkg**.
3. Follow the standard macOS Installer steps.
4. Use your Mac normally. Later Upgrade, Maybe releases can arrive through the signed in-app update path.

Apple silicon and macOS 13.5 or newer are required. The app, installer, and DMG are Developer ID signed, Apple-notarized, stapled, and checked by Gatekeeper. SHA-256 checksum files are published beside both downloadable release archives.
