Upgrade, Maybe 2.2.0 Build 17 adds real temperature and fan evidence to the local Evidence Dashboard so physical heat, Apple thermal pressure, and cooling activity are visible as separate facts.

### Real component temperatures

- Reads trusted Apple-silicon temperature sensors locally and reports CPU, GPU, and SoC values in both Celsius and Fahrenheit.
- Replaces the old text-only thermal tile with a thermometer gauge that moves from green through yellow to red.
- Keeps Apple’s coarse `Nominal` / `Fair` / `Serious` / `Critical` thermal-pressure state visible separately instead of presenting it as a degree reading.

### Temperature and fan history

- Adds the hottest measured component as the aggregate temperature series in the hero system-resource graph.
- Adds dedicated CPU, GPU, and SoC temperature history and fan-speed history for every supported time range.
- Shows current fan RPM, minimum and maximum RPM, and a still/spinning fan state from local hardware evidence.

### Release safety

- The thermal sensor helper, native app, bundled runtime, and every other native helper are Developer ID signed with hardened runtime.
- The installer package and DMG are Apple notarized and stapled.
- Existing local workload and temperature history is preserved when upgrading from Build 16.

### Install

1. Download and open the DMG.
2. Double-click **Upgrade, Maybe.pkg** with the Rally Flags icon.
3. Follow the standard macOS Installer steps.
4. Use your Mac normally. Upgrade, Maybe continues observing locally from the menu bar.

### Requirements

- Apple-silicon Mac
- macOS 13.5 or newer
