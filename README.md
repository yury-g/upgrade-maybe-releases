# Upgrade, Maybe

**Keep without envy. Upgrade without guilt.**

Upgrade, Maybe is a local Mac upgrade reality check. It observes how your actual workload uses your Mac, gives a preliminary opinion after five valid minutes, develops a deeper session view after five valid hours, and reserves an upgrade conclusion for repeated evidence across two adequately observed workdays.

- Metrics stay on your Mac.
- No account, cloud upload, or credit card.
- Apple silicon and macOS 13.5 or newer are required for this public alpha.
- The app and its bundled collector are Developer ID signed and notarized by Apple.

Download the current alpha from the [Upgrade, Maybe 2.2.0 Build 11 release](https://github.com/yury-g/upgrade-maybe-releases/releases/tag/v2.2.0-alpha.3), or learn more at [upgrademaybe.com](https://upgrademaybe.com/).

This repository contains public release downloads and release notes. Product source remains private during the alpha.
